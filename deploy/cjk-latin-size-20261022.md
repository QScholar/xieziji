# 分设中英文字高

- 版本：2026-10-22
- 发布目录：`releases/89df8a2-20261020-live-speed`
- 备份：`deploy/backups/before-cjk-latin-size-20261022162352`

## 行为

排版面板的“字大小（字高）”拆为“中文字高”和“英文字高”，两者均为 2–20 mm，默认相等。

| 场景 | 结果 |
| --- | --- |
| 笔记 · 固定每页行数 | 中文字高由行数与松紧决定，英文字高按用户设定的中英比例自动缩放 |
| 笔记 · 固定字高 | 行距按两者较大值计算，行数自动重算 |
| 表格模式 | 每个字符仍按格子缩放，两个输入隐藏；`latin_size` 不参与 |
| 分页与换行 | 使用每个字符实际高度，中文按中文高度、西文按西文高度 |

后端按字符分类：CJK 汉字、假名、全角形式与中文标点使用中文字高，其余（ASCII 字母、数字、半角标点、希腊字母）使用英文字高。公式仍按基础字高排。

## 接口

`/api/preview` 与 `/api/coordinate-preview` 接受可选 `latin_size`（mm，2–20，缺省等于 `size`）。元数据新增 `latin_size`，`size` 保持中文字高语义。

旧排版预设缺少 `latinSize` 时按 `size` 补齐，无需迁移。

## 部署

```powershell
.\deploy\deploy_cjk_latin_size.ps1
```

脚本校验在线文件哈希、备份、解包、编译、重启 `Xieziji-Web`，并用相同种子分别以 5 mm 与 9 mm 英文字高生成预览，确认英文行变大、中文行不变、控制器 PID 与任务号未变；失败自动回滚。

## 验证记录

- 服务端：`中` 4.018 mm 高保持不变，`A` 在 `latin_size` 5 / 9 / 3 时分别为 6.693 / 12.048 / 4.016 mm。
- 浏览器（127.0.0.1:8080）：中英两行同页预览测得 5.036 mm 与 12.361 mm；固定行数模式下两输入自动为 9.09 / 16.36 mm。
