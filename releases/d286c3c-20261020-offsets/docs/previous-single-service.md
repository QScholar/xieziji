# 写字机 · xieziji

浏览器编辑与预览，连接写字机的电脑运行本地 Python 服务。支持读取 `.gfont` 矢量笔画并生成 G-code，直接通过串口控制已验证的 GRBL 写字机。

**许可：PolyForm Noncommercial 1.0.0。** 本项目供许可允许的非商业用途使用，许可全文见 [LICENSE](LICENSE)。这是源码可用的非商业许可，不称作 OSI 开源许可。第三方字体不随项目分发，其使用与再分发许可由相应权利人决定。

## 功能

- 字体选择与搜索，中文/英文自动换行；调整字高、字距、行数和四边边距。
- 多字体混选，按字符依照自定义权重随机选字体，显示归一化概率和本次实际分布。
- 自定义宽高与独立四边边距的 SVG 笔画预览，下载与预览一致的 G-code。
- 预览显示 XY 正方向和原点，支持反转轴、对调轴、四角起点及浏览器内保存设置。
- 串口枚举与连接、只读原点/配置检查、单任务写入进度、暂停/继续。
- 手动抬笔/落笔、按距离 XY 微动，写字任务期间整区锁定，任务区支持终止。
- 逐条等待 `ok`，报警或通信失败时停止发送并尽力请求 feed hold。
- 完成后抬笔、返回原点，等待实际 Idle 并核对机器坐标。
- 模拟模式和不依赖商业字体的自动化测试。

没有图片转路径、文档导入、多页送纸或任意 G-code 执行接口。现有字体的笔画可读取，字距、基线和换行采用自建排版规则。

## 快速开始

需要 Python **3.10+**。仓库包含原创的简单英文演示字体，可直接运行模拟模式：

```powershell
git clone https://github.com/QScholar/xieziji.git
cd xieziji
.\start.ps1 -Simulate
```

打开 [http://127.0.0.1:8080](http://127.0.0.1:8080)，选择字体、生成预览、连接模拟设备，即可验证完整操作流程，模拟模式不会连接串口或移动机器。

也可以手动启动，适用于 Windows/Linux/macOS：

```bash
python -m venv .venv
# Windows PowerShell
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe -m plotter.server --simulate

# Linux/macOS
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m plotter.server --simulate
```

前端随后端提供，无需 Node 或外部 CDN。代码不依赖 Windows 专用 API，实机验证目前仅在 Windows 完成。

在“字体混选”中选择字体后点“添加”，最多混选 16 种，逐行修改权重。例如 70:30 或 7:3 均对应约 70%:30% 的出现概率，权重 0 的字体不参与。短文本的实际比例会波动；若部分字体缺字，则在支持该字且权重大于 0 的字体中重新分配概率，全部缺字时报错。空白字符不计入分布。

每次生成预览会重新随机，预览下显示本次各字体字数、实际比例和缺字重分配字符数。下载和写入使用该预览缓存的同一份 G-code；修改字体或权重后需重新生成。任务元数据保存随机种子与每个字符的字体索引，API 可使用 `font_mix: [{font_id, weight}, ...]` 和可选 `seed`（1–64 位文本或整数）复现。单独传 `font_id` 的旧接口保持兼容。

预览上方的“XY 坐标调试”支持反转 X/Y、对调 X/Y 及四角起点。`0` 和 `X+`/`Y+` 箭头随设置即时更新，旁边显示输出坐标范围。转换顺序为减去起点在纸张上的位置、交换轴、反转输出轴；可能输出负坐标。文字按纸张排版显示，下载和写入采用对应的转换结果。设置不修改固件轴方向，也不触发点动。

“保存设置”只保存到当前浏览器；修改坐标后需重新生成路径并重新确认机器原点，轴交换后按交换后的纸张尺寸检查行程。API 使用 `coordinate_system: {reverse_x, reverse_y, swap_xy, origin}`，其中三个开关为布尔值，`origin` 为 `top-left`、`top-right`、`bottom-left` 或 `bottom-right`。默认左上起点、不反转、不交换，保持原有输出坐标。

## 接入现有字体与真实设备

将有权使用的 `.gfont` 放入 `gcodeFonts/`，或者指定字体目录：

```powershell
.\start.ps1 -FontDir 'C:\path\to\gcodeFonts'
```

手动启动：

```bash
python -m plotter.server --font-dir /path/to/gcodeFonts
```

选择机器所在串口并连接。将纸张放好，笔位于所选起点角，设备机器坐标为 `(0,0,0)`，方向与预览箭头一致；默认是纸张左上角、X+ 向右、Y+ 向下。生成预览后先检查原点与配置，再勾选确认并点击“开始写字”。网页不提供自动回零、设置原点或解除报警功能。

当前真实设备支持范围：

| 项目 | 已验证配置 |
| --- | --- |
| 固件标识 | `1.3a.20221114` |
| 串口 | 115200 baud、8N1 |
| 抬笔/落笔 | Z0 / Z10 |
| 轴方向 | `$3=7` |
| 每毫米步数 | `$100=80`、`$101=80`、`$102=100` |
| 工作坐标 | G54、G92 与刀具偏移均为零 |
| 限位/回零配置 | `$20=0`、`$21=0`、`$22=0` |
| 默认速度 | 书写 1800、空移/抬落笔 3000 mm/min |

这些参数来自一台已实测设备，服务只检查它们，不修改固件设置。其他设备可能使用不同的轴方向、笔控制或固件，当前版本会拒绝不符合配置的机器。

“暂停”请求控制器减速停下，笔不会自动抬起；“继续”恢复任务。进度是已确认指令数量，未必等于即时纸面完成比例。协议命令说明见 [GRBL 官方文档](https://github.com/gnea/grbl/wiki/Grbl-v1.1-Commands)。

## 远程浏览器使用

后端运行在连接设备的电脑，默认只监听本机。可以通过 SSH 转发使用远端电脑上的设备：

```bash
# 设备电脑：允许客户端转发端口
python -m plotter.server --font-dir /path/to/gcodeFonts --allow-origin-port 18081
# 客户端：保持隧道运行
ssh -N -L 18081:127.0.0.1:8080 user@machine
```

客户端浏览器打开 `http://127.0.0.1:18081`。后端和隧道均需保持运行，本项目未自动配置系统服务或开机启动。

局域网监听必须配置至少 16 位访问令牌，并指定允许的访问地址：

```powershell
$env:PLOTTER_TOKEN = 'replace-with-your-own-long-random-token'
python -m plotter.server --host 0.0.0.0 --allow-host 192.168.1.100
```

替换为实际局域网地址，在网页“服务访问令牌”中填入同一令牌。程序不自动开放防火墙。远程访问优先使用 SSH 隧道。

若明确需要在受信任网络免令牌使用，清除 `PLOTTER_TOKEN` 环境变量，并为启动命令添加 `--allow-unauthenticated`。该选项保留 Host 和跨站请求检查；能够访问服务地址的用户均可操作控制台。

## 任务与状态

任务保存在 `plotter/jobs/<任务编号>/`，包含 G-code、预览、元数据、执行前查询、串口日志与状态。默认保留最近 8 个预览用于启动/下载，旧文件仍留在磁盘；重启后重新生成预览。每份文字最多 3000 字、200000 路径点，只允许同时执行一个任务。

通信失败或控制器报警后，可能仍保留已排队的动作。服务不会自动清空队列、解锁或恢复失败任务；需先在设备端处理、重新定位并重启服务。服务启动不自动连接或写字。退出后端前先完成当前任务。

## 手动控制台

连接后可抬笔（Z0）、单次落笔自动回位，或点击 X+/X−/Y+/Y− 单次移动。距离 0.01–20 mm，速度 50–1000 mm/min，提供 0.1/1/5/10 mm 快捷设置，位置显示机器坐标。方向按机器输出轴，参照预览箭头。手动操作后必须重新定位原点并生成路径；旧预览启动请求会被后端拒绝。

空闲时刷新控制器状态。顶部判断依据控制器回报的 Z0，不代表独立笔尖传感器检测；已在顶部时按钮禁用，后端重新查询后也不会发送多余抬笔指令。手动落笔是 Z10 → Z0 的完整测试动作，可连续触发；起始逻辑坐标非顶部时在同一次动作中先回 Z0，再落笔并回位。若控制器已自行回零则跳过重复回位，每一步等待实际 Idle；取消后不自动发后续动作。写字任务中的抬落笔仍由预览生成的 G-code 控制。

写字任务运行、暂停或等待实际完成期间，整个手动控制台锁定，后端同样拒绝手动指令；任务区的暂停、继续和终止独立工作。正在手动移动时不能启动写字任务或叠加手动动作。正常任务完成后恢复手动控制。

微动使用 [GRBL `$J=` 协议](https://github.com/gnea/grbl/wiki/Grbl-v1.1-Jogging)，不更改普通 G-code 的绝对/相对模式。手动“暂停”与“终止手动动作”发送 jog cancel，取消本次剩余移动，保持连接；不提供自动恢复剩余距离。厂商固件拒绝 `$J=` 时显示错误，不自动改用其他运动方式。功能经过模拟串口与模拟浏览器验证，尚未执行真机微动验收。

“终止任务”停止主机发送、发送 feed hold 与软复位以清除控制器队列，再关闭串口，旧任务不能继续，不自动抬笔或回原点。运动中软复位可能造成位置失准或报警，需在设备端处理并重新确认原点后再连接，见 [GRBL 实时命令说明](https://github.com/gnea/grbl/wiki/Grbl-v1.1-Commands)。

## 测量范围与本次原点（2026-10-16 更新）

先实际移动笔到所选起点角，再测量该点到纸张水平对边的宽和垂直对边的高，单位均为 mm。例如范围 150 × 100，上/下/左/右边距为 7/11/13/17，则可写范围为 120 × 82。边距在测量范围内扣除，不需要输入或手动记录笔的 XY 坐标。

网页填写 `width`、`height`、`margin_top`、`margin_bottom`、`margin_left`、`margin_right`、`rows`、`size`、`spacing`。行距为 `(height-margin_top-margin_bottom)/rows`，各行从对应行位开始，预览显示虚线行位。文字按可写宽度自动换行；不足设定行数留空，超行数或笔画实际越界则拒绝生成，不自动缩小字或截断内容。范围宽高支持 1–600 mm，真实执行仍受设备行程检查限制。旧 API 的统一 `margin` 和显式 `pitch`（未提供 `rows` 时）继续兼容。

写字开始时，已有 G-code 的 `G92 X0 Y0` 将当前物理位置设为本次工作原点；不会先移动到机器 XY 零点，也不写入持久原点设置。允许上一任务留下的 XY 临时偏移，每次开始重新建立。笔必须在 Z0，G54 和刀具偏移仍需为零。结束返回本次工作原点，通过控制器临时偏移核对返回状态。控制台只显示 Z 高度，原始控制器报文仍可用于串口故障诊断。协议依据见 [GRBL 坐标偏移定义](https://github.com/gnea/grbl/blob/master/grbl/gcode.h)。

此次范围与原点更新已部署至校园网服务。47 项发行版测试和 14 项原始字体集成测试通过；线上实测自定义范围、四边边距、四行预览及非零 XY 的只读配置检查通过。更新后 COM5 保持 Idle、Z0，未执行真实运动。备份：`deploy\before-output-layout-20261016170106.tar`。

## 排版预设

“输出范围与排版”中的“排版预设”保留 A4 竖向/横向内置预设，并支持最多 50 个命名自定义预设。设置页面宽高、上下左右边距、字高、行数、字间距与写字速度后，输入名称，点击“另存为新预设”。选择已保存的预设可一键恢复全部参数，修改后可“更新当前预设”，也可删除并在当前页面撤销删除。内置预设不能覆盖或删除，可另存副本。

预设及最后选择保存在当前浏览器当前站点的 `localStorage`（`plotter.layout-presets.v1`），刷新自动恢复最后选中的已保存参数。未点击保存的修改不会覆盖预设。预设不包含正文、字体混选、XY 轴设置、笔位置或原点确认；不跨浏览器/设备共享，清除站点数据会清除预设。载入预设会更新范围引导、使旧任务预览失效，并清除原点确认，需重新生成路径。无效范围或行数不会写入预设；浏览器拒绝存储时明确提示。

预设功能已于 2026-10-16 发布。浏览器验证自定义预设保存、刷新后全部参数恢复、内置/自定义切换、重命名更新、删除/撤销及无效参数拒绝。线上界面与内置预设切换正常。本次仅替换静态文件，串口保持 COM5 已连接、Idle，未发起运动。备份：`deploy\before-layout-presets-20261016170744.tar`。

## 字体组合预设

字体区的“字体组合预设”支持保存所选字体和对应权重（包括权重为 0 的字体），保持顺序。输入名称后点“另存字体预设”；选择预设恢复组合，修改字体或权重后点“更新字体预设”，可同时重命名。支持最多 50 个预设、删除及当前页面撤销删除；删除保留当前混排组合。

字体预设使用当前浏览器站点的 `localStorage`（`plotter.font-presets.v1`），刷新会恢复上次选中的已保存组合，未保存修改不覆盖已有记录。与排版预设独立，不保存正文、页面参数或随机种子；再次预览仍根据权重随机选字。载入组合使旧预览失效并清除原点确认。

预设必须包含 1–16 种不重复字体，权重须为有限数值 0–1000000，至少一种权重大于 0；无效组合不会写入。预设字体在服务端缺失时，选项标记“缺少字体”，载入时明确提示并保留当前组合，不静默丢弃条目或替换字体。预设名称用纯文本显示，存储受限时明确提示。仅在当前浏览器保存，不跨设备同步；清除站点数据会清除预设。

字体组合预设已于 2026-10-16 部署。浏览器验证双字体 70:30 保存/刷新恢复、单/双字体切换、80:20 更新重命名、删除撤销、全零权重拒绝且保留原预设、恢复后生成混排预览。线上入口正常，COM5 保持连接、Idle。本次只更新网页静态文件，未发起真机运动。备份：`deploy\before-font-presets-20261016171242.tar`。

## 仿真控制

“仿真控制”提供总开关及五项独立开关：每字上下浮动、字大小变化、单字旋转、字间距浮动、行基线起伏。字号按单字等比例缩放，整字旋转，原始笔画顺序保留。单字随机参数在换行前固定，按变换后的实际笔画宽度换行；字间距下限为 0。行基线采用随水平位置缓慢变化的正弦起伏，原有行数和行距规则保持不变。全部路径仍通过实际四边边距检查，越界拒绝生成，不截断笔画。

轻微档：±0.15 mm、±3%、±1°、±0.1 mm、±0.2 mm；适中档：±0.3 mm、±5%、±2°、±0.2 mm、±0.4 mm；明显档：±0.6 mm、±10%、±4°、±0.4 mm、±0.8 mm。手动调整或关闭单项后显示“自定义”。全局关闭或所有有效幅度为零时保留原有输出。

“重新随机预览”重新生成路径；当前缓存的预览、下载和实际写入始终使用同一份 G-code。字体选择、每字变化与行起伏使用独立随机序列；API 指定相同 `seed` 可复现。每次网页重新生成默认使用新种子。元数据保存仿真配置、实际种子及逐字变换参数。

API 使用 `humanization: {enabled: true, vertical: 0.3, scale: 5, rotation: 2, spacing: 0.2, baseline: 0.4}`，五项可用对应的 `*_enabled` 布尔值单独开关，默认均为 true。除 `scale` 为百分比、`rotation` 为角度外，其余幅度单位为 mm。上限依次为 2 mm、20%、10°、2 mm、2 mm，参数须为非负有限数字。

保存或更新“排版预设”会同时保存全部仿真开关与幅度；不保存随机种子或具体路径。旧预设自动按关闭仿真载入，字体组合预设保持独立。修改仿真参数会使旧任务预览失效并清除原点确认，需要重新生成路径。

仿真控制已于 2026-10-16 部署，56 项测试通过。模拟浏览器验证三档切换、独立开关、自定义幅度、重新随机路径变化、排版预设保存/刷新恢复及旧预设兼容。线上验证默认单字体仿真预览、只读原点配置检查通过；更新后 COM5 为 Idle、Z0，未执行真机运动。备份：`deploy\before-humanization-20261016174703.tar`。
