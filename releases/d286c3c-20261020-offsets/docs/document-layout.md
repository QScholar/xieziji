# 多页文档、笔记与表格模式

首页先选择笔记或表格模式。字体组合预设继续共用，**排版预设按模式独立保存**；原笔记预设仍可读取，并补上新参数的默认值。切换模式保留各自尚未保存的当前参数。预设保存在当前浏览器、当前站点；“保存整份文档”可下载包含内容、两种模式当前排版、字体选择及坐标的 JSON，在另一浏览器载入。

## 内容与分页

- 文档可以添加、删除和切换预设内容页；每个预设内容页从新纸开始。
- 自动续页：根据实际字宽、公式高度、每页行数或格子容量分页。
- 固定每页内容：任何预设内容页溢出都明确报错，不截断内容。
- `\newpage`、`\pagebreak`、换页符 U+000C 均可显式分页。
- 开头空行、开头空格保留其位置；行末的单个换行符不额外生成空白页。英文自动换行时可能移除作为断行位置的空格。
- 所有页面生成后，右侧切换输出页；输出页与左侧预设内容页可能不是一一对应。
- 空白预设页仍可预览、下载，不能启动空白书写任务。
- 每页对应独立任务 ID、预览、元数据和 G-code。页面切换清除原点确认，已经提交的页面不会在前端重新启用。完成一页后换纸、选择下一页并重新确认原点；没有自动送纸或自动连续启动。
- ZIP 下载包含 `manifest.json` 与逐页 `.gcode`、`.svg`、`.json`。下载与执行都使用缓存结果，不重新随机排版。

新文档最多 30000 个输入字符、100 个预设页、100 个输出页；单页最多 20 万点，整份文档最多 200 万点。预览缓存按整份文档淘汰，最多 8 份且合计最多 200 万点；同一文档超过 8 页不会导致前面的页面立即失效。旧版不带 `layout_mode` 的单页 API 保持原行为及 3000 字限制。

## 笔记排版与中文标点

页面四边边距内按可写宽度换行，每页行距 = 可写高度 / 行数。超过一个行位高度的公式会占用多个行位。内容使用字体公共基线排布，不会把每页第一个非空字重新移动到纸顶。

`punctuation_width` 表示中文标点的最小占位宽度，单位为字高倍数，范围 0–2，默认 0.8。通过留白加宽，不横向拉伸笔画。自动换行尽可能将常见闭标点与前字一起、开标点与后字一起移动；窄到无法容纳这一组合时明确提示调整宽度或字高。

## 表格模式

表格是参考图中的逐字方格，普通字符每字占一格，空格占格，换行进入下一格行；不属于带合并单元格的数据表格编辑器。

可设置行数、列数、行间隔、列间隔、格内边距、字高占可用格高百分比：

```text
格宽 = (可写宽度 - (列数 - 1) × 列间隔) / 列数
格高 = (可写高度 - (行数 - 1) × 行间隔) / 行数
```

内置 A4 表格预设的可写范围为 157 × 215 mm，20 行 × 20 列、行间隔 2.9 mm、列间隔 0，对应格宽 7.85 mm、格高 7.995 mm。字形保持比例并居中，过宽字符会缩小到格内。公式作为整体按格高缩放，并自动占用多个连续格，不会拆成 LaTeX 命令文字。

默认格线仅是预览参考，适用于纸上已有格子的情况；勾选“实际绘制格线”才将格线加入 G-code。共享格边只绘制一次。表格模式以格内比例决定字号，笔记的字高和字间距不直接决定格内尺寸。

## TXT、Markdown 与基础公式

“导入 TXT / Markdown”读取 UTF-8 文件并追加为新预设内容页，不覆盖当前内容。支持 `.txt`、`.md`、`.markdown`；文件最多 512 KiB。格式选择对整份文档生效。Markdown 只将标题、粗体及链接转为普通文字，保留换行与公式；不提供完整 Markdown 页面渲染或图片嵌入。

```text
行内：圆的面积 $S = \pi r^2$。

独立公式：
$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

\newpage

$$\int_0^1 x^2 dx = \frac{1}{3}$$
```

支持 `$...$` / `\(...\)` 行内公式，`$$...$$` / `\[...\]` 独立公式；普通文字中的美元符用 `\$` 转义。支持：

- `\frac`、`\dfrac`、`\tfrac`、`\sqrt`、上下标 `^` / `_`、花括号分组。
- `\sin`、`\cos`、`\tan`、`\log`、`\ln`、`\exp`、`\lim`。
- `\alpha`、`\beta`、`\gamma`、`\delta`、`\theta`、`\lambda`、`\mu`、`\sigma`、`\phi`、`\omega`、`\pi`、`\Delta`、`\Sigma`。
- `\sum`、`\int`、`\infty`、`\times`、`\div`、`\pm`、`\cdot`、`\leq`、`\geq`、`\neq`、`\to`、`\partial`、`\circ`。
- `\text{...}`、`\mathrm{...}`、`\mathbf{...}`、`\operatorname{...}`、`\overline` / `\bar`。字体样式命令保留相同的单线字体，不切换粗细；`\left` / `\right` 支持普通括号但不自动拉伸。

公式生成真实毫米笔画，不执行 TeX、不将截图描边为双线。选中字体缺少 ASCII 字母、数字时，可使用仓库自带的原创单线演示字体回退；常用数学符号使用原创几何笔画。中文仍需所选字体包含对应字形。

这不是完整 TeX 引擎：暂不支持宏、矩阵、环境、可选根次数及复杂对齐。每个公式最多 1000 个字符、嵌套最多 12 层；不支持的命令、未闭合的分隔符、超宽或超高公式都会明确报错。

## 业务 API

`POST /api/preview` 的新文档示例：

```json
{
  "layout_mode": "notebook",
  "pagination": "auto",
  "font_id": "从 /api/fonts 获取",
  "pages": [{"text": "第一预设页\n$x^2$"}, {"text": "第二预设页"}],
  "width": 210, "height": 297,
  "margin_top": 30, "margin_bottom": 30,
  "margin_left": 30, "margin_right": 30,
  "rows": 20, "size": 5, "spacing": 0.9,
  "punctuation_width": 0.8,
  "input_format": "plain",
  "seed": "repeatable"
}
```

表格模式使用 `"layout_mode":"grid"`，并可附加：

```json
{"grid":{"columns":20,"row_gap":2.9,"column_gap":0,"size_percent":80,"padding":0.3,"draw_lines":false}}
```

响应增加 `document_id`、`page_count`、`pages`；每页包含原有 `job_id`、`metadata`、`svg`。原顶层单页字段仍保留，指向第一页。

- `GET /api/jobs/<job_id>/gcode`：当前单页下载。
- `GET /api/documents/<document_id>/archive`：整份 ZIP。
- `POST /api/start`：仍使用单页 `job_id` 和 `origin_confirmed:true`。
- `POST /api/coordinate-preview`：带 `layout_mode` 时返回对应笔记/表格参考页面，不需要连接控制器。

C++ 控制端与串口协议没有改变。
