# 设备配置档案

设备档案按当前控制服务下的串口名区分，存于业务任务目录的 `device-profiles.json`，跨浏览器共享，使用原 API 访问控制。端口号改变时需在新端口重新确认配置，不能将串口备注视为硬件唯一标识。

档案保存设备名称、控制器类型、抬笔与落笔 Z、手动 Z 速度、XY 反转及对调、纸张起点方向、绘图及移动速度、XY 微动距离及速度。选择另一个端口时先保存旧档案，再载入新档案；保存失败则保持原设备。保存按钮及坐标区保存按钮都保存完整档案。

已连接时锁定端口、控制器类型和 Z 控制设置；断开后编辑，下次连接时加载。保存和切换配置本身不发送运动指令。切换会使旧预览和原点确认失效。新预览记录设备端口和 Z 控制参数，控制端在开始前核对，防止在另一台设备上执行。纸张实际原点不存为可复用的校准值，每次执行仍需现场确认。

支持原奎享 GRBL（保留原固件及轴参数核验）与通用 GRBL（不要求原机型固定的固件标识、步进参数和方向参数）。两者均要求 G54、可核验的坐标与行程、空启动脚本及零 Z 工作偏移；不自动写入固件参数。通用 GRBL 设备还须支持现有 `$J`、状态查询、暂停与实时进给倍率协议。此选项不是任意控制板协议适配器，舵机及其他固件协议尚未支持。

Z 值是该设备校准后的机器坐标位置，可能是正值或负值；它们不代表自动寻零、限位或绝对位置传感器。手动抬落笔、任务 G-code、笔状态识别、结束校验和终止回原点均读取本设备配置。

树莓派启用 `PLOTTER_CONTACT_STARTUP=1` 时例外：前端固定显示顶部逻辑 Z0／纸面 Z13.5，机器坐标与逻辑坐标之间的转换由本次人工确认后的上移校准建立，断开或故障即失效。不得将旧机器坐标或旧会话当作新会话的校准结果。此模式及多控制端配置见 [多台写字机与启动校准](multiple-controllers.md)。

验证：`python -m unittest discover -q`，`./controller/build.ps1`，`node tests/test_device_profiles_ui.cjs`（需要 Playwright 与 Edge）。浏览器测试不连接真实设备。自定义 Z 与通用 GRBL 已通过模拟测试，实际设备仍需校准与试写。
